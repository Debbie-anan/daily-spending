# 今日花费 · 本地截图网页版

通过 HTTPS 静态托管后，可在安卓 Chrome / Edge 中添加到桌面。以后刷新可获取网页更新，不需要 APK，也不需要通知权限。

## 隐私和存储
- 仅用同源 GET 下载页面、Tesseract WASM 和识别模型；截图在浏览器内处理，不上传。
- 账本保存在 IndexedDB。清除网站数据、换浏览器、换网址不会自动迁移，请导出 JSON 备份。
- 设置中支持导入原安卓 version 2 JSON 账本，同指纹条目跳过。
- 识别结果须核对后保存。金额、来源、备注、日期和时间均可修改。
- 相同图片指纹不重复记入；同来源、同金额、同一天的记录提示可能重复，默认不选。无法绝对判断是否同一笔，允许确认新增。
- “今天 / 昨天 / 前天”自动换算日期；优先使用截图文件名或画面日期，否则按当前日期计算。旧截图未提供拍摄日期时需要核对结果，不会强制先选日期。
- 首次模型下载需要联网。完成一次识别后模型缓存可供离线使用；浏览器可能回收网站缓存。

## 发布
`web/` 是唯一可公开的静态目录。不得发布 APK 签名、账本、用户截图、测试识别结果或整个项目目录。
用户已于2026-10-19明确授权将 daily-spending 现有仓库改为公开，并通过 GitHub Pages 发布 web/。账本与截图仍仅存于用户浏览器。

静态站点无需构建。Pages 可使用 main 分支根目录。子路径部署受支持，资源使用相对路径。
每次发布同步修改 app.js 中版本、version.json 和 sw.js 的 CACHE 版本。模型缓存单独保留。
