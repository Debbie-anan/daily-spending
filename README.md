# 今日花费 · 0.9 纯离线版

Android 8及以上，主要目标手机为小米13。糖果风界面、今日净额、月历、本月净支出、明细和手动记账。

## 隐私和权限

- APK不声明INTERNET及REQUEST_INSTALL_PACKAGES权限，不联网、不下载界面、不请求安装应用。原在线更新代码及安装包分享Provider已移除。
- 仍需要系统通知使用权才能自动记账。系统授权范围很广，代码过滤不能缩小系统权限。无需授权也可手动记账。
- 仅处理微信、支付宝包名及符合白名单的支付标题。自动识别金额明确的付款、退款，以及支付宝确认转出的转账；微信转账与红包由用户手动录入。
- 新自动记录仅保存渠道、金额、时间和标准摘要，不保存通知全文。既有记录保持原样，可由用户清空。
- 没有短信数据库、联系人、定位、相机、麦克风或无障碍权限。系统通知使用权仍可能接触其他应用的通知，代码在收到后过滤。
- 账本在手机本机。通过系统文件保存器导出时，导出文件由用户自行保管。卸载会清除本机数据。

## 安装和更新

覆盖安装0.9即可保留原账本，请勿卸载。以后更新需要手动安装新版APK，不再支持联网刷新界面。GitHub源码仓库保持私有；先前公开的静态页面不再被本App访问。

## 限制和验证

通知未发出、被隐藏、标题不同、后台中断，都可能漏记。标题白名单不等于密码学验证官方身份。支付宝收支方向或金额不明确时跳过。退款按收到当日抵扣，不关联原订单。关闭网络减少外传和远程更新风险，不消除本机隐私、误判和代码漏洞风险。

已完成规则测试、APK编译和签名验证；检查实际APK没有网络/安装权限、旧更新类和在线入口，并从安装包提取页面验证月历、退款净额、筛选和手动入口。尚未完成小米真机端到端验证。

## 构建

Python3、JDK17、Android SDK platform35和build-tools35，无第三方运行库。

```powershell
python build.py --jdk C:/tools/jdk17 --tools C:/Android/build-tools/35.0.0 --platform C:/Android/platforms/android-35 --work ./build --key C:/private/daily-spending.jks --output ./build/app-release.apk
```

必须使用原签名密钥才能覆盖安装现有应用。密钥只保存在本机，不提交到GitHub或Release。

## 0.9.3 安全检查与修复

检查及限制见 [SECURITY_REVIEW.md](SECURITY_REVIEW.md)。v2账本升级至v3时将旧通知全文摘要化，保留金额、时间和状态；新增导出隐私提示、显式WebView跨源访问限制。不是完整安全认证，通知来源误识别、本机访问及主动导出风险仍在。
