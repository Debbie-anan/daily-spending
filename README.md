# 今日花费 · 0.10.0 纯离线版

Android 8及以上的arm64手机（含小米13），主要目标手机为小米13。糖果风界面、今日净额、月历、本月净支出、明细和手动记账。

## 隐私和权限

- APK不声明INTERNET及REQUEST_INSTALL_PACKAGES权限，不联网、不下载界面、不请求安装应用。原在线更新代码及安装包分享Provider已移除。
- 仍需要系统通知使用权才能自动记账。系统授权范围很广，代码过滤不能缩小系统权限。无需授权也可手动记账。
- 仅处理微信、支付宝包名及符合白名单的支付标题。自动识别金额明确的付款、退款，以及支付宝确认转出的转账；微信转账与红包由用户手动录入。
- 新自动记录仅保存渠道、金额、时间和标准摘要，不保存通知全文。既有记录保持原样，可由用户清空。
- 没有短信数据库、联系人、定位、相机、麦克风或无障碍权限。系统通知使用权仍可能接触其他应用的通知，代码在收到后过滤。
- 账本在手机本机。通过系统文件保存器导出时，导出文件由用户自行保管。卸载会清除本机数据。

## 安装和更新

使用相同签名覆盖安装新版即可保留原账本，请勿卸载。以后更新需要手动安装新版APK，不再支持联网刷新界面。GitHub源码仓库保持私有；先前公开的静态页面不再被本App访问。

## 限制和验证

通知未发出、被隐藏、标题不同、后台中断，都可能漏记。标题白名单不等于密码学验证官方身份。支付宝收支方向或金额不明确时跳过。退款按收到当日抵扣，不关联原订单。关闭网络减少外传和远程更新风险，不消除本机隐私、误判和代码漏洞风险。

已完成规则测试、APK编译和签名验证；检查实际APK没有网络/安装权限、旧更新类和在线入口，并从安装包提取页面验证月历、退款净额、筛选和手动入口。尚未完成小米真机端到端验证。

## 构建

JDK17、Android SDK platform35/build-tools35、Gradle8.9。新增内置中文OCR：`com.google.mlkit:text-recognition-chinese:16.0.1`（bundled，首次识别无需下载模型）。构建依赖下载需要网络，手机运行无联网权限。通过Manifest合并规则移除依赖声明的网络权限；最终APK必须再次检查。

```powershell
$env:JAVA_HOME='C:/tools/jdk17'
$env:ANDROID_HOME='C:/Android/sdk'
$env:LEDGER_SIGNING_KEY='C:/private/daily-spending.jks'
./gradlew.bat testReleaseUnitTest assembleRelease
```

`build.py`提供JVM规则测试、Gradle构建、签名校验和APK导出封装。密钥路径必须显式指定；本机历史测试密钥的别名/口令为localtest/android，不作为生产通用密钥。

必须使用原签名密钥才能覆盖安装现有应用。密钥只保存在本机，不提交到GitHub或Release。

## 0.9.3 安全检查与修复

检查及限制见 [SECURITY_REVIEW.md](SECURITY_REVIEW.md)。v2账本升级至v3时将旧通知全文摘要化，保留金额、时间和状态；新增导出隐私提示、显式WebView跨源访问限制。不是完整安全认证，通知来源误识别、本机访问及主动导出风险仍在。

## 0.9.4 银行卡与消费备注

手动记账渠道增加银行卡；类别增加日常消费，新增最多120字的选填消费备注。备注作为独立note列保存，不混入自动采集的标准摘要。旧记录迁移只添加空备注列；首页银行卡小计、明细渠道筛选、每日及月度净额均包含手动银行卡支出。备注显示采用HTML转义，并在JSON导出中保留。银行App和短信的自动采集没有新增，联网及安装应用权限仍未声明。手动表单可滚动，便于小屏或键盘打开时填写。

## 0.9.5 真实支付宝通知与下拉刷新

修复实际通知“交易提醒：你有一笔15.90元的支出”被旧关键词门槛跳过的问题；适配“退款提醒：你收到一笔13.55元退款”。营销能量提醒及月度支出汇总不计入。

页面滚动至顶部后下拉可刷新；设置页也提供刷新按钮。刷新扫描系统仍保留的通知，并用与实时回调相同的指纹和数据库唯一约束去重；通知监听重连时也扫描现存通知。不读取历史账单，无法恢复已清除通知。不增加权限、联网或通知全文存储。

## 0.10.0 批量截图记账与漏记恢复

- 一张截图识别多笔消费；系统选择器可一次选择最多10张图片。每张最大25MB，超大图片按像素上限缩小。清晰长账单可识别，文字过小请裁剪分段导入。
- 内置离线中文OCR；付款通知、明确实付金额、带负号的账单消费逐条提取。优惠券、余额、汇总和失败付款排除；普通无标记价格不猜测成支出。不是所有App所有账单样式均支持。
- 批量确认列表可勾选、逐笔修改金额、渠道、日期、时间、备注。无年份按当年；缺失日期/时间按当前预填并提示，未知渠道会提示。所有入账需用户核对确认。退款截图抵扣用户确认的日期。
- 同一文件同一候选的SHA-256指纹防重复导入。同日/同渠道/同有符号金额的账本或本批候选标疑似重复，默认不选；确为不同交易可明确确认后保留两笔。日期或渠道识别错误、跨日延迟、跨渠道付款无法保证自动对应，需要人工核对。
- 截图后又收到同日同渠道同金额通知：暂放待核对，不计净额；可在通知页核对后计入或排除。不会静默合并两笔同额真实交易。
- 图片和OCR原文只用于本次内存处理，不复制保存到App文件；仅存确认过的账目、备注及图片候选指纹。系统选择器若自行选择云端文件，下载行为由所选文件服务处理。
- 打开App自动补扫当前通知，监听断开请求重连；付款正文优先从单条通知字段解析，避免扩展字段混入无关汇总导致漏判。增加当前连接与过滤结果，不存被过滤通知原文。
- 用户提供的“交易提醒/你有一笔18.00元的支出”已加入解析和通知到SQLite写入回归测试。旧版也能解析这句，现有证据无法确认手机漏记的唯一原因；系统清除/后台限制/未收到通知等仍可能漏记，补扫只覆盖系统仍保留的通知。

验证包括JVM金额/截图规则、Robolectric通知与数据库集成、APK实际权限/内置模型/签名、安装包页面测试。尚未在小米13真机验证OCR、后台回调或安装；识别结果以手机核对为准。
